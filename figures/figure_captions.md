# Figure Captions

---

**Figure 1. Targeting error distribution per target for each spatial error metric.**
Box plots displaying the distribution of targeting errors across individual targets for four error metrics — Error X, Error Y, Error Z, and Total Error (mm) — under two experimental conditions: the standard adjusted-position phantom setup (top row) and the adapter attachment setup (bottom row). Each box represents the interquartile range (IQR); whiskers extend to the full data range (0th–100th percentile). Overlaid scatter points (jittered horizontally for clarity) represent individual operator measurements. White horizontal lines within each box denote the median, with the median value annotated above. Sample sizes (*n*) are indicated at the base of each group. The adapted position setup uses integer-coded operators (1, 2, 3); rows in which both collar and arc values were absent or zero were excluded prior to analysis.

---

**Figure 2. Per-target mean targeting error comparing the adjusted-position and adapter setups.**
Grouped bar charts showing the mean targeting error for each target, averaged across all operators, under the adjusted-position (blue) and adapter (red) experimental conditions. Results are presented separately for Error X, Error Y, Error Z, and Total Error (mm). Only targets common to both datasets are included. Numerical values are annotated above each bar. This comparison directly quantifies the effect of the adapter attachment on spatial targeting accuracy across individual targets and error axes.

---

**Figure 3. Radar error profiles per target under both experimental conditions.**
Polar (radar/spider) charts illustrating the multi-dimensional error profile of each target for the four error metrics: Error X, Error Y, Error Z, and Total Error (mm). Each panel corresponds to a single target; the top row shows profiles from the adjusted-position setup and the bottom row from the adapter setup. The radial extent of the shaded polygon reflects the magnitude of error along each axis. This representation enables rapid visual comparison of the error "shape" — i.e., which spatial axes contribute most — both within and between experimental conditions.

---

**Figure 4. Heat-maps of targeting error by target and operator.**
Colour-encoded heat-maps displaying mean targeting error as a function of target identity (rows) and operator (columns) for each of the four error metrics. The top row corresponds to the adjusted-position setup; the bottom row corresponds to the adapter setup. Cell colour ranges from green (low error) through yellow to red (high error), with numeric values overlaid on each cell. These maps facilitate identification of operator-specific or target-specific systematic biases and highlight whether measurement variability is attributable to individual operators or inherent target characteristics.

---

**Figure 5. Pearson correlation matrices of targeting error metrics.**
Symmetric heat-maps showing pairwise Pearson correlation coefficients among the four error metrics (Error X, Error Y, Error Z, Total Error) for the adjusted-position setup (left) and the adapter setup (right). Colour encodes correlation strength and direction: red indicates strong positive correlation, white indicates no correlation, and blue indicates negative correlation. Numeric coefficients are overlaid on each cell. A strong positive correlation between component-axis errors and Total Error is expected by construction; cross-axis correlations indicate the presence of systematic directional biases in the targeting procedure.

---

**Figure 8. Stacked-bar decomposition of spatial error contributions per target.**
Stacked bar charts illustrating the relative contribution of each spatial error component — Error X (blue), Error Y (orange), and Error Z (green) — to the cumulative targeting error for each target, averaged across operators. Results for the adjusted-position setup are shown on the left and for the adapter setup on the right; only targets common to both conditions are included. Segment values are annotated within each bar. This figure reveals which spatial axis dominates targeting inaccuracy and whether the directional error pattern is preserved or altered by the introduction of the adapter.

---

**Figure 9. Overall targeting error distribution pooled across all targets.**
Box plots summarising the aggregate distribution of targeting errors across all targets and operators for each of the four error metrics under the adjusted-position setup (top) and the adapter setup (bottom). Each box represents the IQR; whiskers span the full observed range. Overlaid jittered points represent individual measurements, and median values are annotated. Sample sizes (*n*) are shown at the base of each group. This panel provides a concise, single-panel comparison of the overall error magnitude and variability across error axes, enabling direct assessment of total measurement performance under each experimental condition.

# Adjusted-Position Only Figure Captions

---

**Adjusted Figure 1. Targeting error distribution by target for the adjusted-position setup.**
Box plots showing the distribution of targeting errors across all available targets in the adjusted-position sheet for four spatial error metrics: Error X, Error Y, Error Z, and Total Error (mm). Each box represents the interquartile range (IQR), with whiskers spanning the full observed range (0th–100th percentile). Individual operator measurements are overlaid as jittered scatter points to visualise raw dispersion. White median lines are drawn within each box, and the corresponding median values are annotated. Sample sizes (*n*) are shown at the base of each target group. This figure provides a target-level view of measurement spread, central tendency, and outlier-free variability within the adjusted-position experiment.

---

**Adjusted Figure 2. Per-target mean and standard deviation of targeting error in the adjusted-position setup.**
Bar charts displaying the mean targeting error for each target in the adjusted-position sheet, shown separately for Error X, Error Y, Error Z, and Total Error (mm). Error bars indicate the standard deviation across operator measurements, and the mean value for each target is annotated above the corresponding bar. By summarising the average magnitude and spread of each metric, this figure highlights which targets are associated with systematically larger errors or greater operator-to-operator variability.

---

**Adjusted Figure 3. Heat-maps of targeting error by target and operator for the adjusted-position setup.**
Colour-encoded heat-maps showing the mean error value for each combination of target (rows) and operator (columns) across the four error metrics. Cell colour transitions from low-error green through yellow to high-error red, with numerical values overlaid in each cell. This presentation helps identify whether elevated targeting error is concentrated in specific targets, specific operators, or distinct target-operator combinations, thereby supporting interpretation of systematic procedural bias within the adjusted-position condition.

---

**Adjusted Figure 4. Mean multi-metric error profile for each target in the adjusted-position setup.**
Line plots illustrating the mean error profile of every target across the four measured metrics: Error X, Error Y, Error Z, and Total Error (mm). Each line corresponds to a single target, allowing direct comparison of how the relative contribution of each error axis changes from one target to another. This figure is useful for identifying target-specific error signatures and for determining whether certain targets exhibit disproportionate error along a particular spatial dimension.

---

**Adjusted Figure 5. Pearson correlation matrix of targeting error metrics for the adjusted-position setup.**
Heat-map of pairwise Pearson correlation coefficients among Error X, Error Y, Error Z, and Total Error for all adjusted-position measurements. Red indicates positive correlation, white indicates weak or negligible correlation, and blue indicates negative correlation; numerical coefficients are overlaid within each matrix cell. This figure characterises the degree to which spatial error components co-vary and helps reveal whether larger total error is driven uniformly across axes or dominated by specific directional contributions.

---

**Adjusted Figure 6. Operator-level comparison of total targeting error in the adjusted-position setup.**
Box plots comparing the distribution of Total Error (mm) across operators, pooled over all targets in the adjusted-position sheet. Each box summarises the operator-specific IQR, whiskers span the full observed range, and individual observations are shown as jittered points. Median values are annotated directly on the plot. This figure provides a compact assessment of inter-operator consistency and highlights whether one operator tends to produce systematically lower or higher overall targeting error than the others.
